## 为什么 Dropbox 不成功
首先，最核心的一点是产品定位错误。Dropbox 把自己长期定位成面向普通消费者的 C 端云盘工具，而不是企业的生产力工具。云盘本质上是“生产力工具”，真正愿意付费的是企业而不是个人用户，这个方向一开始就选错了。
其次，是被早期的病毒式增长误导。最初通过“邀请码 + 送免费空间”的活动，Dropbox 在 C 端获得了巨大成功，这让团队更加坚信“面向消费者”这条路是对的，结果后续决策都围绕 C 端展开，错过了更有商业价值的 B 端市场，相当于被自己的成功困住了。
第三，是商业模式与用户动机不匹配。文章强调，企业愿意为提高员工效率付费，而大多数消费者“只想消磨时间，不想节省时间”，所以不会愿意为提高效率的软件掏很多钱。Dropbox 却主要靠消费者付费提升收入，导致营收长期上不去，在互联网大发展的十年里反而停滞甚至萎缩。
最后，是缺乏面向新市场的扩张路线。因为始终围绕 C 端打转，Dropbox 没有主动把自己升级为企业协作、团队文件工作流等更高价值的生产力平台，结果在云计算与 SaaS 大潮中，增长空间被自己锁死，这被作者视为 Dropbox 无法持续发展的根本原因。
