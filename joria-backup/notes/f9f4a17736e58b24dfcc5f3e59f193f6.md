Richard Sutton 也在两个月前的 WAIC 上提到，value function 是下一代范式的一个关键组件。
在他看来，Reward 只描述当前收到的好坏信号，而 value function 能评估当前处境未来可能带来的整体后果。
Agent 不能只追求明确的奖励信号，也仍然需要价值函数，才能把眼前收益和长远结果联系起来。
